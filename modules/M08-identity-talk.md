# Identity／Talk 與其他應用

**狀態：** 公用知識框架，尚未逐功能驗證。
**版本適用性：** 依實際 UniFi OS / Application / Firmware / API 與設備功能；未標示者為「需實測驗證」。

## 核心概念
Identity、Endpoint、MFA、Talk、Connect、EV Station。依官方能力和版本區分支援範圍，不預設所有產品相同。

## 官方建議做法
閱讀對應產品及版本官方文件；採最小權限與最小變更面積。此條為 Skill 維運原則，不能替代具體版本的官方指引。

## UI 操作路徑
不同 Network 與 Application 版本可能不同，需比對官方截圖與現行 UI；此版本不提供未驗證的固定路徑。

## CLI / API 替代方法
僅使用當前版本官方明列、文件化的 API。禁止將未公開 Legacy API 當正式支援介面。

## 常見情境範例
通用規劃 → 資料來源核對 → 變更前備份 → 測試 → 驗收 → 審核。

## 風險與注意事項
避免斷網、錯誤 VLAN、管理介面鎖定、帳號過權或設備不可用；敏感操作須經使用者授權。

## 驗證方式
文件來源、產品支援矩陣、軟韌體版本、預期結果與回滾均須逐項驗收。無真實測試不可標記實機 PASS。

## 故障排除流程
辨識症狀 → 核對版本及支援限制 → 最小範圍重現 → 蒐集非敏感日誌 → 驗證回滾。不要直接改生產設定。
