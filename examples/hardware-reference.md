# UniFi 公開產品規格如何正確引用

此文件不存放任何使用者現有設備清單或私人網路設定。

適合教學的資料欄位：`model`、`product_category`、`supported_app`、`switch_port_capabilities`、`poe_budget`、`uplink_speed`、`source_url`、`doc_checked_on`。

先查 https://techspecs.ui.com/ 及 https://ui.com/ 的特定產品規格，確認是否適用本硬體 revision 與 Region，**不能把 UniFi 家族的一個型號功能套用到所有型號**。

示例僅能用合成／公開規格資料，不要求真實 MAC、IP、Serial、Topology 或憑證。
